# Documentation guide

The documents in this directory use the following status labels:

- **Proved in Lean:** a declaration exists in the repository and compiles.
- **Computational observation:** a finite script or explicit example exhibits
  the stated behavior. This is not a proof of a universal statement.
- **Open:** no proof is present in the repository.
- **Historical program:** an earlier proof strategy retained for its verified
  lemmas or diagnostic value.

Start with these files:

- `solution-status.md`: canonical current proof status and unresolved endpoint.
- `big-picture.md`: concise technical overview.
- `laymen-progress.md`: non-specialist explanation.
- `literature-erdos881.md`: problem statement and relevant published results.

The remaining files describe earlier programs or special cases:

- `flood-structure-theorem.md`: order-two structural consequences of a
  hypothetical counterexample.
- `rank-program.md`: the well-founded-rank approach and its unresolved step.
- `positional-program.md`: a superseded order-two positional approach.
- `salvage-audit.md`: reusable modules from earlier work.
- `thin-basis-campaign.md`: finite experiments on digit-type thin bases.
- `unbounded-gaps.md`: proved bounded-gap and geometric reflection cases.

Historical chronological logs were removed during the 2026-08-03
documentation consolidation. They remain available in version control.
